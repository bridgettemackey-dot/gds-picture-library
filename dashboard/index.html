A zero is not always a zero

Buffer's API fills in 0 both when nobody did the thing and when the network never reported it. The two are indistinguishable from the outside. Instagram saves, shares and follows read 0 on all 52 posts ever published there — that is far more likely to be Meta not reporting them through the API than 52 posts nobody ever saved. Treat a flat zero column as “no data”, and a number that moves as real.
